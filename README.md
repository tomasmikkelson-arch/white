# Білий список ІМІ

Лендинг «Списку прозорих і відповідальних медіа» Інституту масової інформації: що таке Білий список, три останні випуски з обкладинками, методологія та архів усіх моніторингів з 2019 року.

Статичний сайт без збірки: `index.html` + `assets/`. Публікується через GitHub Pages (`.github/workflows/pages.yml`) при кожному пуші в `main`.

## Що де лежить

- `assets/style.css` — стилі (фірмовий синій ІМІ `#405BFF`, шрифти KyivType Sans і Overpass, локально в `assets/fonts/`)
- `assets/img/cover-*.webp` — обкладинки трьох останніх випусків
- `assets/wl-logo.svg` — **тимчасовий** знак Білого списку, замінити на векторний оригінал
- `assets/imi-logo.svg` — логотип ІМІ

## Як додати новий випуск

1. Покласти обкладинку в `assets/img/` (webp, ~1600 px завширшки + копія 800 px).
2. У `index.html` новий випуск стає великою карткою в `#latest`, поточна велика переходить праворуч, а нижня права картка — в архів (`.tile`).
3. Оновити цифри в першому екрані: кількість медіа, графік `.bars`, перелік медіа `.roster__list`.
